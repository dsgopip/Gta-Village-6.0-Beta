VILLAGE LIFE 3D — VERSION 9.1

Исправления относительно V9:
- Исправлено горизонтальное направление джойстика персонажа (лево/право).
- Исправлено направление вращения камеры при свайпе по экрану.
- Переработано расположение мини-карты в горизонтальной ориентации: она уменьшена и закреплена в верхнем правом углу, чтобы не перекрывать правые кнопки управления.

Установка: замените все файлы проекта в корне GitHub Pages. Важно загрузить engine.js и textures-inline.js.
Three.js загружается с CDN, поэтому для запуска требуется интернет.
