VILLAGE LIFE 3D — ЮБИЛЕЙНАЯ VERSION 10.0

V10 основана на загруженном проекте V9.1 и включает:
- Переписанное ядро симуляции в engine.js (V10Engine).
- Исправленное направление движения: джойстик вправо ведёт персонажа вправо.
- Камера управляется свайпом по любой свободной части экрана; кнопки и джойстики исключены.
- Обновлённая плавность камеры, движение персонажа и анимация жителей.
- Переработанная аркадная физика автомобиля: разгон, торможение, сцепление, боковое скольжение и повреждения.
- Более подробная мини-карта с дорогами, домами, полицией, медпунктом, школой, магазином, игроком, машиной и котом.
- Обновлённая процедурная текстура шерсти кота и дополнительные детали мордочки и лап.
- Компактная мини-карта в альбомной ориентации, не перекрывающая кнопки управления.

Установка:
1. Распакуйте архив.
2. Замените ВСЕ файлы в корне GitHub Pages.
3. Убедитесь, что загружены engine.js и textures-inline.js.
4. Commit changes и откройте сайт GitHub Pages.

Требования: современный мобильный браузер с WebGL и подключением к интернету.
Three.js загружается с jsDelivr CDN. Это самостоятельный браузерный проект, не APK.

Проверки: синтаксис JavaScript и структура ZIP проверены. Реальный запуск на физическом Android-устройстве не выполнялся.
