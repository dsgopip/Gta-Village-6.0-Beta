VILLAGE LIFE 3D — мобильный прототип

КАК ЗАПУСТИТЬ:
1. Загрузите ВСЕ файлы из этой папки в корень GitHub-репозитория.
2. В GitHub откройте Settings -> Pages.
3. Выберите Deploy from a branch, branch main, folder /(root), Save.
4. Откройте опубликованный HTTPS-адрес в Chrome на Android.

УПРАВЛЕНИЕ:
ПЕШКОМ:
- левый джойстик: движение и поворот
- БЕГ: удерживать
- ТОЛКНУТЬ: игровое взаимодействие с ближайшим жителем
- В МАШИНУ: сесть рядом с автомобилем

В МАШИНЕ:
- левый джойстик: только поворот
- ВПЕРЁД: разгон (удерживать)
- НАЗАД: торможение/задний ход (удерживать)
- ВЫЙТИ: покинуть машину

КАМЕРА:
- кнопка КАМЕРА переключает 3-е и 1-е лицо.

ВАЖНО:
Это ранний игровой прототип, а не готовая GTA-подобная игра.
Требуется интернет для загрузки Three.js с CDN при первом открытии.
В прототипе есть простая деревня, 3D-персонаж, серый кот, машина, жители,
смена дня/ночи, переключение камеры и базовая система повреждений.
Ragdoll пока представлен упрощённой анимацией падения/отшативания.
Модели и физика будут улучшаться следующими версиями.
