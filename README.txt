VILLAGE LIFE 3D — VERSION 8.0

V8 changes:
- Camera can be rotated by dragging across any free part of the screen. Touch controls and buttons are excluded from camera-look input.
- Reworked on-foot controls with smoother acceleration/deceleration, responsive turning and animated walking/running limbs.
- Textured player outfit, skin, hair and shoes; car keeps its procedural metallic paint and detailed cockpit materials.
- Live minimap marks police station, clinic, school and shop, plus player/car position.
- Existing village, NPCs, cat, buildings, vehicle, missions and day/night cycle retained.

Install/update: upload all six project files to the root of the GitHub Pages repository, replacing previous files, then commit.
Three.js is loaded from jsDelivr, so an internet connection is required. This is a browser/PWA project, not an APK.
