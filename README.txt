VILLAGE LIFE 3D — VERSION 9.0

V9 introduces a rebuilt runtime architecture in engine.js: fixed-step simulation, isolated touch input, new character controller, revised vehicle dynamics, smoothed follow camera, companion-follow AI and a detailed live minimap.

Files: index.html, style.css, game.js, engine.js, textures-inline.js, manifest.webmanifest. Upload all seven files to the repository root, including the new engine.js module.

The game uses Three.js 0.160.0 from jsDelivr, so an internet connection is required. This is a browser/PWA project, not an Android APK.

Controls: left joystick to move, RUN to sprint; while driving use steering joystick and separate forward/reverse pedals. Drag anywhere except buttons and joysticks to rotate the camera. Camera button toggles first/third person.

Mini-map shows police station, clinic, school, shop, roads and the live player/car position. The grey tabby companion uses a generated 1024px fur texture and a detailed model.
